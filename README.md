# ExamPortal – Online Examination Management System

## Overview

ExamPortal is a web-based examination management system developed using Google Apps Script and Google Sheets. It simplifies examination administration by managing student registrations, exam links, online assessments, automated evaluation, results, retakes, and certificate generation.

## Features

- Student registration and management
- Exam configuration and question bank management
- Unique exam links using secure tokens
- Online examinations with time limits
- Automatic answer evaluation and result generation
- Automatic submission of overdue attempts
- Retake examination links
- Admin review of examination attempts
- PDF certificate generation and email delivery
- Data backup and monthly reset functionality

## Technology Stack

- Google Apps Script
- Google Sheets
- JavaScript
- HTML
- Google Drive
- Gmail

## Project Workflow

1. Students register for an examination.
2. Registration details are stored in Google Sheets.
3. Administrators send examination links.
4. Students access and complete their examinations.
5. The system saves answers and evaluates submissions.
6. Results are updated automatically.
7. Eligible students receive PDF certificates.
8. Administrators can review attempts and issue retake links.
